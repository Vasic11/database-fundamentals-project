# Database Application - Desktop App with JavaFX

This repository contains a full database-driven desktop application developed as part of the **Database Fundamentals** course at **Računarski fakultet (RAF)**. 

The project bridges the gap between relational database design and application development, featuring a graphical user interface (GUI) built with JavaFX that communicates directly with an SQL database.

## 🚀 Key Features & Implementation
- **JavaFX User Interface:** Designed an intuitive and responsive GUI for data visualization and management.
- **Java & Database Connectivity:** Implemented database connection logic (JDBC/Hibernate) to allow the Java application to securely perform CRUD (Create, Read, Update, Delete) operations.
- **Relational Database Design:** Formulated relational schemas and applied normalization techniques (1NF, 2NF, 3NF) to ensure data integrity.
- **Advanced SQL Querying:** Integrated complex SQL scripts inside the backend logic using multi-table `JOIN` operations, aggregations, and subqueries.

## 🛠️ Tech Stack
- **Frontend / UI:** JavaFX, FXML
- **Backend / Core:** Java (OOP)
- **Database:** SQL, Relational Databases
- **Tools:** Git, Scene Builder (if used)

## 📂 Project Structure
- `/src` - Java source code, JavaFX controllers, and database connection logic.
- `/scripts` - SQL scripts for schema creation and initial data insertion.
